dbwarp-blueprint 1.5.1 release binaries.

Release highlights:
- Blueprint schema v6 is retained; compression sample encodings remain a
  separate compatibility boundary.
- Binary-payload measurement, precompressed-payload profiles, bounded
  compression probes, and statistics-freshness reporting are improved.
- Adaptive MySQL and SQL Server sampling retries respect the projected payload
  budget and record remaining prefix bias; MySQL truncation detection accounts
  for connection character-set conversion.
- Source and binary archives include CHANGELOG.md, SUPPORT.md, and
  CONTRIBUTING.md alongside audit references and least-privilege scripts. See
  CHANGELOG.md for rollout caveats and version-specific changes.
- Complete human-facing catalogs remain embedded for English, German, French,
  Spanish, Polish, Japanese, and Simplified Chinese.
- English documentation is authoritative. Included machine-translated
  documents are supplemental, may lag English corrections, and may contain
  errors.
- Option names, accepted values, URI schemes, selectors, DBP codes, audit
  fields, anonymous identifiers, and emitted TOML/bundle schemas remain
  canonical English tokens.

Trust paths:
- Small source build: clone this repository, review the source, and build with
  Cargo.lock.
- Offline audit build: download dbwarp-blueprint-source-vendored.tar.gz, review
  the included vendor/mysql_async patch and vendor-crates/ dependency tree, and
  run ./build.sh inside the extracted tree.
- Convenience path: download a platform binary, verify its SHA256, and review
  the matching source tag.

Runtime security model:
- The binary sends no telemetry.
- Live modes initiate the configured database connection. The operating system
  and configured identity or TLS path may also contact the DNS resolver or
  KDC/domain controller as documented in AUDIT.md.
- The output Blueprint file is local until you choose to share it.

Download the archive for your platform, then verify it against SHA256SUMS.txt
before running.
