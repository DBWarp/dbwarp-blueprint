# Terminal lockup

These checked-in lockups are derived from the approved DBWarp SVG geometry and
DM Sans. The artwork generator is not part of this source distribution. Do not
redraw or hand-edit individual variants; replace the derived set together.

Default lockup is the drawn slant art `dbwarp-ascii.txt` / `dbwarp-ansi-glyph.txt`.
`--banner-mode half|blocks|braille` still uses the SVG-sampled rasters.
