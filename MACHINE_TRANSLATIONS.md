# Machine-translated material

English is the authoritative language for DBWarp Blueprint source,
documentation, command behavior, permissions, security statements, and file
formats. English documentation is the release-blocking documentation contract.

Non-English user-interface catalogs and translated documents are produced with
machine assistance. They are supplemental, may lag the current English source,
and may contain mistranslations, awkward wording, or technical errors.
Canonical command names, option names, accepted values, URI schemes,
identifiers, message codes, audit keys, and emitted file schemas remain English
in every locale.

Do not rely on a translation for a security, regulatory, contractual, or
least-privilege decision without comparing it with the English source. Please
report translation problems through the public repository issue tracker.

Runtime locale catalogs are tested against the live command and message
surface. That structural coverage does not prove linguistic accuracy. Review
of translated documents is maintained on its own cycle and does not block an
otherwise qualified English release.
