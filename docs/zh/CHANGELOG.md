## 1.5.1

### 采集与保真度

- 保持 Blueprint 模式 v6，区分目录估算、采样观测以及无法获取的统计信息新鲜度证据。
- 改进二进制负载测量、已压缩负载的特征分析和有界压缩探针。
  不同 `sample_encoding` 值对应的比率不可互换；消费方必须先识别编码，才能使用测量值。
- 限制 MySQL 和 SQL Server 自适应采样重试的规模，包括过大值及字符集转换引起的扩张。
  记录仍然存在的前缀偏差，同时保留原始采样值的长度元数据。
- 修正连接字符集改变返回字节长度时的 MySQL 截断检测。
- 改进共享 Blueprint 核心对合成值长度、基数、分布和局部性的处理。

### 运维与审查

- 明确专用最小权限账户设置、源码构建步骤、对比构建验证以及已通过资格验证的数据库版本矩阵。
- 更新机器翻译文档和运行时措辞，继续以英文为准，译文作为补充材料。
- 加强公开源码中可执行文件权限模式和发布归档的检查。
- 在源码和二进制分发包中加入发布历史、支持和贡献指南。
- 删除未使用的 ASCII 图案，不改变受支持的横幅模式。

### 兼容性与推出

现有 Blueprint 仍可由新采集器读取，但反向兼容不受保证：1.5.0 读取器会拒绝新增的
可选字段 `sample_layout`，旧消费方也可能拒绝新的压缩样本编码。
因此，仅有模式 v6 解析器并不能证明前向兼容。
在将新采集结果用于演示文稿、合成生成或基于压缩的规划之前，请将消费工具与采集器一起升级并验证。

请固定确切的发布成果物和校验和。旧版本的资格验证不能证明另一二进制文件会产生相同结果。
